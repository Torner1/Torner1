### 🚀 Selected projects

**OpticalLamp — Smartphone optical communication**  
An Android application exploring Morse communication through light,
with flashlight transmission, adjustable speed and a Jetpack Compose
interface. Camera-based reception is my next development focus.

`Kotlin` `Jetpack Compose` `Android` `Optical Communication`

**FPGA Function Generator — Digital waveform generation**  
A DE1-SoC project generating PWM and sine-wave signals from
10 Hz to 10 kHz, using a sine lookup table, TLC7524 DAC
and seven-segment display.

`VHDL` `FPGA` `ModelSim` `Digital Electronics`

**Web Applications & Automation**  
Practical applications and connected workflows, with a focus on
clear interfaces and maintainable software.

`TypeScript` `Next.js` `Supabase` `Automation`
